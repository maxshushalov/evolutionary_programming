# Лабораторная работа №4

Сравнение генетического и меметического алгоритмов для доставки с ограничениями грузоподъёмности и временными окнами.

Дисциплина: «Эволюционное программирование и генетические алгоритмы». N = 29, группа 507, Q = 0, Y = 26, вариант 20. Для собственной темы преподаватель разрешил свободный выбор. Проект самостоятельный, предыдущие лабораторные не нужны.

## Установка

Нужен python 3.10 или новее. Фактическая версия и зависимости проведённых серий записаны в `results/main/metadata.json` и `requirements-lock.txt`. Ключевые алгоритмы используют стандартную библиотеку; matplotlib и numpy нужны для таблиц и графиков.

Откройте в терминале папку `evolutionary_programming_lab4` и выполните:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Для повторения точных версий зависимостей можно установить `requirements-lock.txt` вместо `requirements.txt`. После установки программа работает без сетевого доступа. Готовое окружение `.venv` предназначено только для текущей машины; при переносе создать его заново.

## Быстрый запуск

Входные данные и результаты уже приложены. Для чтения результатов ничего пересчитывать не требуется. Отчёт: [REPORT.md](REPORT.md). Порядок чтения кода: [HOW_TO_READ.md](HOW_TO_READ.md). Сценарий защиты: [DEMO.md](DEMO.md).

```bash
.venv/bin/python -m unittest -v
.venv/bin/python run.py single --instance data/instance_40.json --method memetic --seed 1000
.venv/bin/python run.py validate --output results/main
.venv/bin/python plots.py --results results/main
```

Одиночный запуск сохраняется в `results/single_memetic_1000.json`. Другой путь задаётся через `--output`.

## Повторение экспериментов

Все параметры находятся в `config.json`. `generate` детерминированно создаёт экземпляры по seed данных; случайность поисковых запусков задаётся отдельно.

```bash
.venv/bin/python run.py generate
.venv/bin/python run.py exact
.venv/bin/python run.py pilot --output results/pilot_repeat
.venv/bin/python run.py experiments --output results/repeat
.venv/bin/python run.py validate --output results/repeat
.venv/bin/python plots.py --results results/repeat --output figures/repeat
```

Папка серии должна быть пустой или отсутствовать. Это защищает исходные результаты от смешивания с повторными. При повторении использовать новое имя папки. Команда `generate` перезаписывает только детерминированные файлы данных; после изменения генератора прежние результаты проверяются по сохранённым хешам, поэтому исходные данные следует сохранить отдельно.

Серия состоит из 180 основных запусков и 30 дополнительных для исследования числа шагов локального поиска. В каждом запуске ровно 20000 оценок. Сходимость строится по оценкам, а не по поколениям. Одинаковый seed воспроизводит решение, историю и счётчики в том же программном окружении; время выполнения может различаться.

## Состав проекта

| Файл или папка | Содержание |
|---|---|
| `problem.py` | Данные, кодирование, время движения, цель и ограничения |
| `algorithms.py` | Операторы, отбор, локальный поиск, основной цикл и бюджет |
| `run.py` | Команды запуска, серии, полный перебор и валидация |
| `plots.py` | Статистика, CSV, графики и выбор демонстрационного запуска |
| `test_lab4.py` | Проверки модели, алгоритмов и сохранённых результатов |
| `data/` | 3 основных экземпляра и маленький контрольный пример |
| `data/validation/` | Контрольные маршруты генератора; поиск их не читает |
| `results/main/` | 210 отдельных JSON, таблицы, метаданные и снимок исходников |
| `results/pilot_v1/`, `results/pilot_v2/` | Два этапа пилота с исходными конфигурациями |
| `results/exact_control.json` | Ответ полного перебора 5040 решений |
| `figures/` | Графики сходимости, распределения, маршрутов и времени |
| `PROTOCOL.md` | Изменение инициализации после первого пилота и итоговый протокол |
| `PLAN.md`, `TOPIC.md` | Исторический план и заявка, подготовленные перед кодом |

Исследование использует синтетические данные, постоянную скорость и одинаковые машины. Известные контрольные маршруты не передаются алгоритмам, однако генератор и геометрическая часть инициализации используют сходную структуру. Выводы относятся к этим экземплярам. Глобальная оптимальность основных результатов не доказана.
