# Проверки перед публикацией

Проверено на macOS с Python 3.14.0; версии вычислительных библиотек
сохранены в `experiment_metadata.json`.

- `python -m pip check`: конфликтов зависимостей нет.
- `python -m src.objective`: значения в точках −1, 0 и 1 проверены.
- `python -m unittest discover -s tests -v`: **21 тест, все пройдены, пропусков нет**.
- Операторы: корректность турнира и кроссовера, независимая мутация,
  clipping, неизменность родителей, нечётное число потомков.
- Популяция: допустимость координат, постоянный размер, сохранение элиты,
  невозрастание лучшего значения, корректный рекорд при выключенном элитизме.
- Бюджет: реальные вызовы HGBat перехвачены тестом; проверены бюджеты
  10, 11, 18, 19, 20 и 123 при популяции 10. Оба метода расходуют ровно бюджет.
- Seed: повторяемость обоих методов и изменение результата при другом seed.
- Config A/B: отличаются только `mutation_sigma`.
- Полная серия: 3 метода × 20 seed × 50 000 оценок = **3 000 000 оценок**.
- Итоговые CSV содержат по 20 запусков; каждая из двух историй ГА содержит
  10 120 строк (20 × 506), включая инициализацию и неполное поколение.
- Значения функции пересчитаны по сохранённым координатам, статистика сверена
  с исходными CSV, используется `ddof=1`.
- Дополнительно полностью повторён Config A, seed 0 через CLI в окончательном
  `.venv`: координаты, значение и вся история побитово совпали с полной серией.
- Оба PNG открыты и проверены визуально: подписи, легенды и диапазоны читаемы.
- Notebook выполнен настоящим ядром Jupyter из `project-1`, `notebooks` и корня
  репозитория: все шесть кодовых ячеек успешно выполнены в каждом случае.
  Выполненный ноутбук сохранён с таблицами и графиками.

Smoke-тесты и дополнительный одиночный запуск использовали временные каталоги
и не подменяли итоговую серию. Отчёт заполнен только фактически полученными
числами; незаполненных TODO нет. Достижение теоретического минимума не заявляется.
