# Лабораторная №3. Настройка игрового ИИ

Трек A, вариант 20. В крестиках-ноликах собственный NSGA-II настраивает глубину minimax, веса эвристики и вероятность случайного хода. Сравниваются доля побед, время выбора хода и разнообразие действий. Готовых оптимизаторов и сторонних зависимостей нет.

Для чтения работы начните с [отчёта](report.md), [плана](PLAN.md) и файла [«Как читать код»](Как%20читать%20код.md).

Требуется python 3.10 или новее. Из папки лабораторной:

```bash
python3 data_setup.py
python3 -m unittest discover -s tests -v
python3 run.py --pilot
python3 run.py --single nsga2 --seed 0
python3 run.py --all
```

Параметры находятся в `config.json`. Данные уже сохранены в `data/train.json` и `data/test.json`; команда `data_setup.py` воспроизводит их. `run.py --pilot` проверяет короткую серию, `--single` запускает один метод, `--all` проводит 20 запусков каждого из 3 методов. Результаты помещаются в разные папки `results/`. Повторный запуск в занятую папку намеренно останавливается, чтобы не перезаписать эксперимент. Для новой полной серии переименуйте старую папку `results/experiment`.

`results/experiment/runs.csv` и `summary.json` содержат статистику, файлы `run_*.json` содержат все оценки и историю. Графики в SVG открываются браузером. Для повторной генерации статистики из уже сохранённых запусков:

```bash
python3 analysis.py results/experiment
```

Оценка времени зависит от нагрузки компьютера. Seed воспроизводит данные, игровые партии и действия алгоритма при фиксированных оценках, но живой таймер не гарантирует побитового совпадения полной серии.
